how to run the code? 
1. Install python version 3.11 or newer (instructions can be found online)
2. install the required modules: tkinter, cv2, numpy, matplotlib (instructions can be found online)
3. run maingui.py to access the frontend or main1.py directly as backend
4. select the image via "Browse" in the "Process Images" Notebook to open a file, then enter the Pixel Size and Gradient Threshold
5. Klick "Analyze Particles" to find the Particles, the use the other Buttons to plot the Results

6. Feel Free to play around with the code, if u use the code to obtain data for a paper, please give me credit (Moritz Limbacher)
